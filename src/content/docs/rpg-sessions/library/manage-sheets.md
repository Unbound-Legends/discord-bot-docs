Your sheets stay in the Library even when a game uses them. The Game Table reads the current values from that source sheet, so edits there carry into play.

## Organize with folders

1. Open **Library** and select **Create New**.
2. Choose **Folder** and give it a recognizable name.
3. Use folders for a campaign, a group of adversaries, a setting, or retired content.
4. Use the Library path to move between the root and nested folders.

Search and filters work alongside folders. A consistent naming pattern makes similar adversaries and vehicle variants easier to distinguish.

## Open and update a sheet

Select a Library card to open the full sheet. The sheet header provides the actions available to you, which can include:

- **Update** to refresh calculated or linked values when the sheet supports it.
- **Print** to open a print-friendly version.
- **Clone** to create a separate copy.
- **Edit** to change the sheet's fields.

Characters, adversaries, and vehicles don't all have the same controls. You also need edit permission before the editing actions appear.

## Clone before making a variant

Clone a sheet when you need a similar adversary, a different equipment loadout, or a second version of a vehicle. Rename the clone immediately so it isn't mistaken for the original.

A clone is a separate sheet. Later changes to the original don't automatically copy to it.

## Add or remove a sheet from a game

Game membership and Library ownership are separate. Removing a sheet from a roster doesn't delete it from your Library. Deleting a game doesn't delete the sheets that used to be in its roster.

Before removing anything, check whether you're acting on:

- The actor's membership in one game.
- The complete sheet in your Library.
- A shared item in the Data Library.

## Delete carefully

Delete a sheet only when you no longer need the source. Check every game that uses it, clone or print anything you want to keep, and read the confirmation before you continue.

If an action is missing, see [Roles and Visibility](/docs/rpg-sessions/reference/roles-and-visibility). If a sheet disappeared unexpectedly, start with [Troubleshooting](/docs/rpg-sessions/troubleshooting#library-and-sheet-access).
