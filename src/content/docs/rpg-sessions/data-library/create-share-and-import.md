Create your own data when the campaign needs an item, talent, action, encounter, or Map that you can't find from the source you want. Keep it reusable instead of adding state that belongs to one character.

## Create an entry

1. Open the matching Data Library category.
2. Select the create control when it's available.
3. Enter a clear name and source.
4. Fill in the structured rule fields for that item type.
5. Add a description and notes needed to use it correctly.
6. Save, reopen the entry, and verify the displayed values.

Create a reusable weapon in **Weapon**, not as free-form gear. Put a vehicle check in **Vehicle Action**, and use **Quality** for a rule that should be attached to multiple items.

## Build a kit

Use a kit to group related data.

1. Open **Kits** and select **Create Kit** when the control is available.
2. Give the kit a recognizable name and description.
3. Add the items that belong together.
4. Review the item count and source labels.
5. Test the kit with a non-critical sheet before distributing it.

Keep unrelated campaign data in separate kits so users can import or use only what they need.

## Import a kit

Select **Import Kit** and add the package the importer asks for. When it finishes, compare the item count and check a few weapons, talents, qualities, and attachments.

An import can finish successfully and still contain references that don't work for your theme. Open a few representative items and check them before you rely on the kit.

## Share and export

Sharing and export actions vary by data type, ownership, status, and current feature access. Use the action shown on the item or kit rather than assuming every category has the same workflow.

Before sharing:

- Remove private campaign notes and personal information.
- Confirm the rules source and whether you have permission to distribute the content.
- Use a clear version or update note when other people already depend on the data.
- Test imported references and granted effects.

## Avoid feature-state claims in written guides

The signed-in site is the source of truth for create, share, import, export, and promotion controls. If one is missing, check ownership and current access before you rebuild the item somewhere else.

For failed or incomplete imports, see [Troubleshooting](/docs/rpg-sessions/troubleshooting#imports).
