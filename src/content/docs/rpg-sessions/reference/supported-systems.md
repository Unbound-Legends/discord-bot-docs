RPG Sessions supports the related narrative dice rules from the Star Wars Roleplaying Game and Genesys. Your game theme controls the terminology, presentation, dice style, and optional fields you'll see.

## Star Wars Roleplaying Game

Star Wars themes give you the six characteristics, narrative dice, skills, adversary types, weapons, armor, gear, talents, vehicles, Force options, and campaign mechanics used across Edge of the Empire, Age of Rebellion, and Force and Destiny.

The theme and sheet options decide whether a character shows obligation, duty, morality, Force rating, and the related fields.

## Genesys

Genesys themes use the same six core characteristics and narrative-dice foundation while allowing setting-specific skills, talents, equipment, magic, and other optional mechanics.

The exact fields follow the selected game theme rather than one universal Genesys setting.

## Numeric dice

The standalone Dice page also provides a Numeric theme for rolls that don't use the narrative symbols. It's a dice option, not a replacement game theme for narrative character and vehicle sheets.

## Theme choices matter

You choose a game theme and dice theme when creating a game. You also choose a theme when creating a character or vehicle.

For the best compatibility:

- Use sheets whose theme matches the intended game.
- Choose data-library items from a compatible source or system.
- Review optional mechanics during sheet creation.
- Test imports before relying on them in a session.
- Avoid changing a long-running game's theme without reviewing its sheets and rules data.

## Availability versus support

A supported data type or workflow can still depend on feature access, your role, or the table settings. Check the signed-in site for the controls your account has now.
