If you're new to RPG Sessions, start here. Set up your account, then build a sheet, join a game, or create a table for your group.

## 1. Create or open your account

Open [rpgsessions.com](https://rpgsessions.com) and choose **Sign Up** if you don't have an account. If you already have one, choose **Log In**.

After you sign in, the home page gives you shortcuts back to recent games, sheets, and rolls. The top navigation takes you to every main area.

## 2. Learn the navigation

- **Library** contains your characters, adversaries, vehicles, and folders.
- **Dice** opens the standalone narrative dice roller and roll history.
- **Games** lists games you created or joined.
- **Data** opens reusable game content such as kits, weapons, armor, talents, and encounters.
- **Profile** contains account details, preferences, connections, images, tokens, and developer access.

An **Admin** link only appears for site administrators. It isn't part of the normal player or GM workflow.

## 3. Choose your first task

### Build a character or vehicle

Open **Library**, select **Create New**, and choose the kind of sheet you need. See [Create Sheets](/docs/rpg-sessions/library/create-sheets) for the full process.

### Import an existing sheet

Open **Library**, select **Import**, and choose the matching source. Import options depend on the kind of data that the external tool exports. See [Import Sheets](/docs/rpg-sessions/library/imports).

### Join a game

Ask the GM for the game link. Open it while signed in, then choose **Join Game** if the table accepts new players. Some games use Drop-In Mode and may ask for a password instead.

### Create a game

Open **Games**, select **New Game**, and follow [Creating a Game](/docs/rpg-sessions/guides/creating-a-game).

## Optional connections

Open **Profile** to link Discord or Patreon. You only need Discord for features that use the [Discord Bot](/docs/discord-bot). Patreon and table-token options depend on the access tied to your account.
